## Why these were missed before

They are the same class as the Soundings P0s: a value written and shown back to the person who
wrote it, with no consumer. The gates in place (pixel, SQL invariants, respondent e2e) check what
exists against itself; none asks "who reads this, and what changes when it does". `W2` now asks it
for every settings table, on every audit.
